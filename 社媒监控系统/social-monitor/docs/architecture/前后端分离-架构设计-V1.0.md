# 前后端分离重构计划与进度

## 当前结论

当前项目已经完成前后端分离的主体框架：`frontend` 是 Vue 3 + Vite 前端工程，`server.js` 提供 Express API，并在生产环境托管 `frontend/dist`。

整体进度评估：100%。阶段 1、2、3、4 均已完成，权限体系和部署流程已优化。阶段 5（UI 对齐）已完成。

## 目标架构

- 前端使用 Vue 3、Vite、Pinia、Vue Router、Element Plus。
- 后端使用 Express 提供 `/api/*` JSON 接口。
- 开发环境由 Vite 代理 `/api` 和 `/media` 到后端。
- 生产环境由 Express 托管 `frontend/dist`，并保留 `/api` 和 `/media` 服务。
- 鉴权使用 JWT，前端统一注入 Bearer Token，后端统一校验。
- 前端 UI 设计、布局、视觉风格和核心交互需要与现有版本保持一致，重构优先做等价迁移。
