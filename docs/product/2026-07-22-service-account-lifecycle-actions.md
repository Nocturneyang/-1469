# 服务账号退出与彻底删除

日期：2026-07-22

## 目标

服务账号卡片为管理员同时提供“退出登录”和“彻底删除”两个动作，并明确区分数据影响：

- 退出登录：终止当前 WA/TG 渠道 session，停止该账号 runtime worker，保留账号记录、历史消息、分组、配置和审计。
- 彻底删除：删除该账号全部历史消息、账号配置、作业数据、runtime 数据、session、媒体文件和 outbox；不可恢复。

## 交互

- 两个按钮始终位于服务账号卡片底部。
- “退出登录”使用普通确认框，文案明确“保留历史消息和配置”。
- “彻底删除”使用两次确认：第一次说明完整删除范围；第二次再次确认不可恢复。
- 账号仍在线时不允许直接删除，管理员必须先退出登录，待状态变为“已退出”后再执行彻底删除。
- 操作进行中禁用当前账号的生命周期按钮，避免重复提交。

## 状态

```text
ready/authenticated -> logout_requested -> logged_out
logged_out/disconnected/requires_login -> deleted
```

“已接入”只表示真实可运行状态；`logout_requested` 显示“退出中”，`logged_out` 显示“已退出”。
