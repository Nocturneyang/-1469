# 三列客服工作台与会话处理栏

## 定位

工作台继续只做独立登录、服务账号接入、收发、权限、已读和内部协作，不接入监控分析、AI、供应商画像或可靠性评分。

桌面作业区正式采用三列结构：

1. 会话列表。
2. 消息线程与回复框。
3. 当前会话处理栏。

客户资料对象固定为 `platform + service_account + group_id`，不跨渠道合并客户。

## 信息布局

### 顶部工作队列

- 只保留平台、未读/全部、服务账号和标签/分组筛选。
- 移除客户类型筛选；搜索框位于会话列表顶部。
- 同步为右上角轻量操作，不再单独占行。

### 会话列表

- 每条会话展示群名、前两个标签、会话状态、服务账号、最新消息、时间和未读数。
- 标签仅用于扫读，点击整行进入会话，不在列表中编辑。

### 消息线程顶部

- 左侧为头像、群名、平台、服务账号和可回复状态。
- 右侧为当前会话标签区，直接展示最多五个标签；超出显示 `+N`。
- 渠道原生标签/分组带渠道前缀并只读；工作台标签可在这里直接编辑。
- 移除“打开原生会话”和默认展开的消息搜索工具条。

### 第三列信息顺序

1. 会话状态。
2. 最近三条内部备注及新增入口。
3. 当前查看/输入坐席和最近三条操作记录。
4. 可折叠的账号在线、发送开关和熔断状态；异常时自动展开。

不展示负责人、认领、移交、优先级、星标、跟进提醒、负责人备注和风险评分。历史字段继续保留兼容。

客户类型不再在新 UI、筛选或服务账号设置中呈现；历史字段与接口继续保留兼容，不要求坐席填写。

## 权限

- `can_view`：查看会话处理信息、备注、协作状态和动态。
- `can_reply` 或 `can_manage`：新增内部备注。
- `can_manage`：修改会话状态和工作台标签。
- 渠道原生标签或文件夹永远只读；编辑工作台标签不会写回 WA/TG。

坐席停用或入口权限关闭后，下一次请求必须立即拒绝，不能依赖前端隐藏。

## 响应式

- 大屏固定显示三列。
- 中等宽度压缩服务账号导航。
- 小于 1180px 时会话处理栏改为右侧抽屉。
- 手机端抽屉全宽，不允许横向溢出。
