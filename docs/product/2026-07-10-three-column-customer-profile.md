# 三列客服工作台与客户资料栏

## 定位

工作台继续只做独立登录、服务账号接入、收发、权限、已读和内部协作，不接入监控分析、AI、供应商画像或可靠性评分。

桌面作业区正式采用三列结构：

1. 会话列表。
2. 消息线程与回复框。
3. 当前会话客户资料栏。

客户资料对象固定为 `platform + service_account + group_id`，不跨渠道合并客户。

## 第三列信息顺序

1. 内部名称、渠道原生群名、平台和服务账号。
2. 客户类型与会话状态。
3. 可编辑工作台标签、只读渠道标签或文件夹。
4. 查看/回复权限、账号在线、发送开关和熔断状态。
5. 最近三条内部备注及新增入口。
6. 当前查看/输入坐席和最近三条操作记录。

不展示负责人、认领、移交、优先级、星标、跟进提醒、负责人备注和风险评分。历史字段继续保留兼容。

## 权限

- `can_view`：查看资料、备注、协作状态和动态。
- `can_reply` 或 `can_manage`：新增内部备注。
- `can_manage`：修改内部名称、客户类型、会话状态和工作台标签。
- 管理员：维护服务账号自己的客户类型选项。

坐席停用或入口权限关闭后，下一次请求必须立即拒绝，不能依赖前端隐藏。

## 响应式

- 大屏固定显示三列。
- 中等宽度压缩服务账号导航。
- 小于 1180px 时客户资料栏改为右侧抽屉。
- 手机端抽屉全宽，不允许横向溢出。
