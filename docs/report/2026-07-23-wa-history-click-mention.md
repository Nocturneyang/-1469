# WA 聊天记录点击提及交付记录

日期：2026-07-23

## 变更

- WA 群聊中，已由群成员快照确认身份的入站发送人支持点击头像或姓名插入提及。
- 原有回复框“提及群成员”选择器继续保留。
- 两个入口共用同一套 Composer 提及逻辑：正文写入 `@显示名`，外发账本单独保存 WA 原生成员 ID。
- 消息发送人的 LID、手机号与 phone ID 只在能够唯一匹配群成员快照时才生成可点击提及目标；匹配缺失或歧义时不开放点击，避免误提及。

## 验证

- `npm test`：通过。
- `npm run build`：通过。
- 隔离本地页面验证：
  - 点击聊天记录发送人“王小明”，回复框插入 `@王小明`。
  - 使用原有“提及群成员”选择器，回复框同样插入 `@王小明`。
  - 浏览器控制台无 error/warning。
  - 未点击发送，未使用真实 WA 账号执行外发。

## 发布与回滚

- 功能验证阶段仅使用本地隔离数据；生产发布后也不使用真实 WA 账号执行测试外发。
- 回滚时可移除消息接口的 `sender_mention_id` / `sender_mention_name` 增强及前端 `mention-sender` 事件；原有工具栏提及选择器不受影响。
