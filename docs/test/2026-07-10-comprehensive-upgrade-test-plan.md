# 综合升级测试计划

必须覆盖：

- 停用、入口关闭、范围撤销和只读备注拒绝。
- 默认环境不执行真实发送。
- URL、localStorage 和日志不出现 SSO Token。
- 幂等、串行、引用、ACK、FloodWait、PeerFlood、限速、重启恢复和 `dead`。
- 入站媒体落盘、鉴权读取、越权拒绝和危险类型下载策略。
- 客户类型在新 UI、筛选和服务账号页均不呈现；历史字段保持兼容。
- 三列布局、会话头部最多五个标签、标签编辑浮层、1180px 抽屉、390px 手机端和长文本。
- 数据库备份、`quick_check` 和临时恢复。
- `npm test`、生产构建、`npm ls` 与依赖安全审计。

真实渠道端到端验证只允许使用测试账号。
