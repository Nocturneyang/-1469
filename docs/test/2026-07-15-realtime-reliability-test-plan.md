# 工作台实时与可靠性测试计划

日期：2026-07-15

## 自动化

- schema 可重复初始化，旧数据库自动补齐新字段和表。
- 全局 SSE 校验登录、账号范围、`Last-Event-ID`、心跳和断线清理。
- WA ACK 1/2/3/4、重复 ACK、乱序 ACK 均不导致状态降级。
- 两个坐席并发认领只有一个成功；覆盖归属和释放他人需要管理权限。
- 同一账号多个消费者只能有一个领取任务。
- 发送租约续期、已知远端 ID 恢复、未知结果暂停均有覆盖。
- 可重试错误进入延迟队列；不可重试错误进入 `dead`；每次尝试保留审计。
- 外发附件数据库中不再保存 `data_url`，路径越界和文件缺失必须失败。
- 超级管理员、可信代理和本地免登录的新默认值有回归测试。
- `/readyz`、`/metrics` 和运行事件清理不包含消息正文或 secret。

## 前端

- 当前会话和群列表收到 SSE 后刷新，断线时显示连接状态并保留轮询保险。
- WA 外发显示灰色单勾、灰色双勾、蓝色双勾；失败状态不使用勾号。
- 桌面通知必须由用户操作授权，页面标题未读数可恢复。
- 文本草稿按坐席和会话隔离，发送成功清除，创建失败保留。
- 桌面和 390px 窄屏不发生状态图标、长群名或附件名称重叠。

## 发布门禁

```text
npm test
npm run build
node --check <changed commonjs files>
npm run predeploy:check
```

生产发布后只验证 SSO 跳转、运行配置、Pod ready、日志和只读健康状态。真实渠道外发和 ACK 仅使用显式测试账号人工冒烟。
