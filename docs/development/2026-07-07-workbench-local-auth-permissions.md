# 工作台本地登录与权限配置入口

日期：2026-07-07

## 背景

工作台已从监控项目拆分为独立部署项目，需要提供工作台自己的账号登录入口和权限配置入口。登录、角色、入口权限和服务账号范围必须使用工作台自己的 SQLite 文件，不得写入或依赖监控项目的 SQLite。

## 实现边界

- 本地登录账号存储在 `auth.sqlite` 的 `users` 表。
- 角色、权限项、入口权限、服务账号/分组范围存储在 `workbench.sqlite`。
- 管理 API 挂在 `/api/workbench/admin/*`，由工作台自己的 `can_admin` 权限保护。
- 前端 `/login` 提供工作台账号登录，并保留统一登录按钮。
- 前端 `/admin` 提供权限配置入口，可创建账号、配置角色、入口权限和服务账号/分组范围。
- Deploy Hub 的 `sso` 已改为 `false`，避免平台网关先拦截 `/login`；应用 API 仍由工作台 token/SSO token 鉴权保护。

## 首次管理员

生产环境首次使用本地账号登录时，需要通过 `INITIAL_ADMIN_PASSWORD` 创建初始 `admin` 用户，或提前在 `auth.sqlite` 中准备管理员账号。已有 SSO 超级管理员仍可通过统一登录进入并管理工作台权限。
